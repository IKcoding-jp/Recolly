# ゲーム検索改善（関連度ソート導入・Wikipedia補完の高速化）設計書

作成日: 2026-07-17
ステータス: 承認済み（実装完了）

## 背景と目的

ゲーム検索には2つの不満がある。

1. **遅い**: 日本語クエリではWikipedia補完（英語タイトル取得→IGDB再検索→説明取得）を
   最大10タイトル×3回＝約30回の直列HTTP呼び出しで行っており、初回検索が数秒かかる
2. **並び順が悪い**: ソートが「品質（画像・説明の有無）→人気度」のみで、
   検索語との関連度を考慮していない。無関係な人気作が上位に出ることがある

本改善で「関連度×人気のバランス」の並び順と、体感1秒強までの高速化を実現する。

## スコープ

- 対象: バックエンドの検索パイプライン（`WorkSearchService` / `IgdbAdapter`）
- 関連度ソートは全メディア共通の `WorkSearchService` に入れるため、
  ゲーム以外（アニメ・映画・本等）の検索順にも効く（意図した副次効果）
- フロントエンドの変更なし（APIレスポンス順のまま表示している）

## 設計

### 1. 関連度スコア（新規: `SearchRelevanceScorer`)

`backend/app/services/search_relevance_scorer.rb` を新設する。

- `SearchTextNormalizer.normalize` でクエリと結果タイトルを正規化して比較
- 関連度ティア（4段階）:

| ティア | 条件 | 例（クエリ「ゼルダ」） |
|--------|------|------------------------|
| 3 | 完全一致 | 「ゼルダ」 |
| 2 | 前方一致（タイトルがクエリで始まる） | 「ゼルダの伝説」 |
| 1 | 部分一致（タイトルがクエリを含む） | 「リンクの冒険 ゼルダの伝説2」 |
| 0 | 不一致 | 「マリオカート」 |

- 表記揺れ（全角/半角・大小文字・空白）は正規化で吸収する
- 略称（「ドラクエ」→「ドラゴンクエスト」）の展開はスコープ外

### 2. ソート順の変更（`WorkSearchService`）

現行の2段ソート「品質降順→人気度降順」を、3段ソートに変更する。

```
関連度ティア降順 → 品質スコア降順 → 人気度降順
```

- 関連度が同じ作品グループの中では、情報が揃っていて人気のある作品が先に並ぶ
- ソートは全メディア共通処理のため、`quality_score` と同様にサービス内に実装する

### 3. Wikipedia補完の高速化（`IgdbAdapter`）

- タイトルごとの「英語タイトル取得→IGDB再検索」チェーンを直列→**並列化**する
  （`WorkSearchService#fetch_from_adapters_in_parallel` と同じThread方式）
- 検索時の `fetch_extract`（Wikipedia説明文取得）を**廃止**する。
  説明は記録時の1作品補完（ADR-0044）に統一する
- 並列化に伴い、重複排除（`existing_ids`）は全スレッド完了後にまとめて行う
  （Setをスレッド間で共有せず、競合状態を避ける）
- 1タイトルあたりのHTTP呼び出しが3回→2回に減り、
  全体の所要時間は「直列合計」から「最も遅い1チェーン分」に短縮される

### 4. キャッシュ

- `WorkSearchService::CACHE_VERSION` を v8 → v9 に更新
  （並び順と補完内容が変わるため旧キャッシュを無効化する）

### 5. エラーハンドリング

- 並列化した各スレッドは個別に rescue し、1タイトルの失敗が他タイトルに波及しない
- Wikipedia補完全体の rescue（既存の `search_via_wikipedia` 内）は維持する

## テスト方針（TDD）

### 単体テスト

- `SearchRelevanceScorer`: 完全一致・前方一致・部分一致・不一致・表記揺れ吸収
- `WorkSearchService`: 関連度が品質・人気より優先されるソート順
- `IgdbAdapter`: 並列補完後も結果が正しくマージされること、
  検索時に `fetch_extract` を呼ばないこと（WebMock）

### 実タイトル検証（動作確認ステップ）

実装後、実際のタイトルでテストケースを設計し、検索アルゴリズムの妥当性を確認する。

検証観点の例:

| 検索語 | 期待する挙動 |
|--------|--------------|
| ゼルダ | ゼルダシリーズが上位に固まり、人気作が先頭に来る |
| ファイナルファンタジー | ナンバリング作品が上位。無関係作品が混ざらない |
| マイナーな日本語タイトル | Wikipedia補完経由でヒットする（ヒット率が落ちていない） |
| 英語タイトル（例: Celeste） | 従来どおりヒットする |

検証時は初回検索の体感速度（キャッシュなし状態）も併せて確認する。

## 決定事項の記録

- 並び順アルゴリズムは「関連度ティア方式」を採用（重み付き合算・IGDB順信頼は不採用）
- 高速化は「並列化＋検索時説明取得の廃止」を採用（補完件数の制限は不採用）
- 詳細はADRに記録する
